🔐 Publicação direta no GitHub

Para eliminar ZIP, descompactação e vários commits, esta Central pode publicar tudo diretamente no GitHub em um único commit. Use um Fine-grained Personal Access Token do GitHub com acesso somente ao repositório vendedores-reino e permissão Contents: Read and write. O token não será gravado em arquivo nem enviado para outro servidor; ele fica apenas na memória desta página.
Nenhuma publicação executada nesta sessão.

Fluxo recomendado

1. Atualize vendedores e ranking, se necessário.
2. Faça as alterações dos cards e da Vitrine nesta Central.
3. Abra Pré-visualização e confira tudo.
4. Importe os novos vendedores.json/ranking.json na área Publicação Completa (se foram alterados).
5. Abra a etapa 4 • PUBLICAR e toque em PUBLICAR TUDO • 1 COMMIT.
6. Pronto. O GitHub recebe todas as alterações de uma vez.
